# Baabel プロモ動画シナリオ（SNS 用・約 35 秒・16:9）

**狙い**：最初の 3 秒で「JS が羊の鳴き声になって動く」ことを見せ、中盤で「羊語は飾りではなく本当に動くソース」だと分からせて、最後は「命令セットを変えるとコンパイラごと作り直される」で締める。
**音声なし**でも伝わるように、画面下にテロップを常に出す（SNS では無音で再生されることが多いため）。

| # | 時間 | 画面 | テロップ | 見せたいこと |
|---|---|---|---|---|
| 0 | 0.0–2.0s | タイトルカード（🐑 Baabel / JavaScript → 羊語 → WebAssembly）がフェードアウト | — | 何のアプリかを一瞬で伝える |
| 1 | 2.0–8.5s | 左ペインに `console.log("Hello, World!");` をタイピング。打つそばから中央に「メェ→メェメェ群れ…」が湧き、右に `Hello, World!` が出る | 「JavaScript を書くと…」→「羊語にコンパイルされて、WebAssembly で動く」 | **フック**。3 ペインが連動してリアルタイムに流れる気持ちよさ |
| 2 | 8.5–15s | カーソルが中央の最初の「メェ！」（出力命令）へ移動。その直前に「メェ」を 1 つ打ち込むと、出力が `Ifmmp-!Xpsme"` に変わる | 「羊語はただの飾りじゃない。これが実行されるソース」→「メェを 1 つ足すと、全部 1 文字ずれる 🐑」 | **核心**。羊語を書き換えると結果が変わる＝本物の言語 |
| 3 | 15–20s | サンプルから FizzBuzz を選ぶ。中央が長い羊語になり、右に 1, 2, Fizz… が流れる | 「FizzBuzz も羊語で動く」 | ちゃんとしたプログラムも動く |
| 4 | 20–28s | 命令セットを 猫語 → 絵文字 → BrainPower → Whitefuck と次々切り替える。中央の見た目は毎回変わるが、右の出力は同じ | 「命令セットは自由に変えられる」→「変えるたびに、専用コンパイラ（.wasm）をその場で生成」 | 方言が変わっても意味は同じ／コンパイラ生成 |
| 5 | 28–32.5s | 右の「コンパイラ」タブを開き、生成された Wasm コンパイラの逆アセンブルをスクロール | 「コンパイラ自体も WebAssembly。Wasm が Wasm を書き出す」 | 技術的な見どころ（エンジニア向けの一撃） |
| 6 | 32.5–36s | エンドカード（🐑 Baabel / ブラウザだけで動く / github.com/shunmoridev/Baabel） | — | 行き先を残す |

## 投稿文の例

> JavaScript を「羊語」にコンパイルして、WebAssembly で動かすやつを作りました 🐑
> 羊語は見た目だけじゃなく、本当に実行されるソース。命令セットを変えると、その言語専用のコンパイラ（.wasm）をブラウザ内で生成します。
> 猫語・絵文字・Whitefuck も。
> https://github.com/shunmoridev/Baabel

## 録画

```bash
npm run promo
```

`vite build` → プレビューサーバー起動 → Playwright（Chromium）で上の台本どおりに操作 → `promo/out/baabel-promo-ja.mp4`（1920×1080 / H.264）を書き出します。
英語版は `npm run promo -- en` です。
